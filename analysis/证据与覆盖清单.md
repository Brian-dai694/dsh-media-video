## 可复核的重要证据锚点

### video-editor

- `src/components/UploadView.tsx`：POST `/api/video/merge`、多文件视频上传。
- `src/page/ProcessVideo.tsx`：视频播放/Canvas 帧预览、处理页参数与 `/api/video/process` 请求。
- `src/components/TransformDrawer.tsx`：转码请求 `/api/video/trans`、下载结果与码率字段。
- `src/page/DetectPage.tsx`：前端检测结果 `detectionList` 展示/处理。
- `server/src/controller/video.controller.ts`：正式项目 controller 的视频流、上传/merge/process 路由入口。
- `server/src/service/video.service.ts`：视频处理服务，需后续函数级阅读确认具体算法。
- `server/test.ts`：独立 Express + Multer + FFmpeg overlay `/api/replace-face` 示例；不可当成正式 Midway 服务路由。
- `server/src/service/upload.service.ts`：存在后续分析服务 TODO。

### OpenReel

- `README.md`：多轨视频/音频/文本/图形、转场、关键帧、SRT 字幕、音频混音/淡入淡出/EQ/压缩/ducking、画幅和导出、AI 助手、web/desktop 差异。
- `docs/AGENT-CAPABILITIES.md`：agent 工具能力大表（体积约 130KB；本次检视只做局部检索，不能保证所有条目已核验）。
- `packages/agent/src/registry.ts`、`executor.ts`、`loop.ts`、`llm.ts`：工具注册、执行、对话循环、provider request/response 适配。
- `packages/core/src/actions/registry.ts`：编辑动作注册及 inverse action 入口。
- `packages/agent-runner/src/run.ts`、`project-io.ts`：无头编辑与项目文件读写入口。
- `apps/desktop/src/aurora-host/`：原生渲染/预览/序列 session。
- `packages/image-core/src/schema.ts`、`apps/image/src/tools/`：独立图像编辑状态 schema 与工具实现。
- `apps/cloud/src/marketplace/`：授权、限流、存储、自动检查与制品构建。

### ComeCut

- `README_ZH.md`：Beta / Web + desktop 的产品自述；ASR→翻译→TTS→视频合成；AI 助手；音频分离/还原；抠图/GIF；本地保存等声明。
- `guide/ai-features.html`、`guide/roadmap.html`：指南与路线声明。
- `web/assets/plugins/plugin-whisper/index.js`：动态依赖 Hugging Face Transformers CDN 的线索。
- 主要编辑器 bundle 超过静态工具解析大小限制；源码不可见，所以只能按“文档声明”引用产品功能。

### HunyuanVideo-1.5

- `README_CN.md`：模型介绍、T2V/I2V、SSTA/DiT、VSR、硬件与系统要求、生态说明。
- `generate.py`：CLI 输入、T2V/I2V 分支、分辨率、SR、prompt rewrite、offloading/cache/distillation 等运行参数。
- `train.py`：训练/并行/FSDP/gradient checkpoint/validation 等代码入口。
- `hyvideo/pipelines/`：主推理与视频超分 pipeline。
- 权重需要外部下载且不在 ZIP 中；没有执行。
